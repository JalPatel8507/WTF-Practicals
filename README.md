# Practical: Server-Side Web Application Using Node.js and Express.js

## Aim
To develop a basic server-side web application using Node.js and Express.js demonstrating routing, request-response handling, session management and user authentication.

## Technologies Used
- Node.js
- Express.js
- Express-session
- JavaScript
- Visual Studio Code

## Features
1. Home page
2. About page
3. User login system
4. Session-based authentication
5. Protected Dashboard
6. Logout functionality

## Routes

| Route | Description |
|---|---|
| / | Home |
| /about | About |
| /login | Login |
| /dashboard | Protected Dashboard |
| /logout | Logout |

## How to Run

1. Install Node.js.
2. Install dependencies using `npm install`.
3. Run the application using `node server.js`.
4. Open `http://localhost:3000` in a browser.

## Conclusion
Successfully developed a server-side web application using Node.js and Express.js with multiple routes, session management, authentication and access control.
